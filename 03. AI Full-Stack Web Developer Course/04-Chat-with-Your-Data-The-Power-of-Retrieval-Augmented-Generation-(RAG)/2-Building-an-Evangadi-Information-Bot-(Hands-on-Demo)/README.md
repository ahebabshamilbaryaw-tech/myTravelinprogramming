# Building an Evangadi Information Bot – Hands-on Demo

## 📖 Overview

This project is a practical implementation of a Retrieval-Augmented Generation (RAG) application.

The goal is to build an **Evangadi Information Bot** that can retrieve relevant information from a knowledge source and use it to generate helpful, context-based answers.

## 🎯 Project Objectives

- Understand how a RAG application works in practice.
- Prepare and process a knowledge source.
- Split documents into manageable chunks.
- Generate embeddings from text.
- Store and retrieve relevant information.
- Connect retrieved context to an AI model.
- Generate answers grounded in the available information.
